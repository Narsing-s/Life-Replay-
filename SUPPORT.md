# Support

Need help with Life Replay?

## Before opening a support request

1. Read the [README](README.md).
2. Check the [Deployment Guide](docs/DEPLOYMENT.md).
3. Check the [API Reference](docs/API.md).
4. Search existing GitHub issues for the same problem.

## Bug reports

Use the repository **Bug Report** issue template and include:

- Browser and operating system
- Node.js version, if running locally
- Exact reproduction steps
- Expected behavior
- Actual behavior
- Relevant console/server logs with secrets and personal data removed

Never attach private photos, passwords, JWTs, API keys, databases, or other sensitive memory data.

## Security issues

Do not report security vulnerabilities in a public issue. Follow [SECURITY.md](SECURITY.md).

## Feature requests

Use the **Feature Request** issue template and explain the user problem, proposed solution, and why it would improve Life Replay.
